# Calculator

A simple and interactive calculator built using HTML, CSS, and JavaScript.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus operation
- Decimal calculations
- AC button to clear the display
- DEL button to delete the last character
- Modern dark-themed interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
